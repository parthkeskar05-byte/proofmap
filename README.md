# ProofMap

ProofMap turns one AI/ML job description into a clear map of resume-backed skills, project evidence, and requirements not mentioned in the resume.

## What it does

- Detects a focused set of AI, ML, RAG, NLP, and production-engineering signals in a pasted role description.
- Connects supported signals to evidence from the resume, including project details and measured results.
- Flags recognized requirements that are not mentioned in the resume without treating them as proof of missing ability.
- Reports transparent evidence coverage, not an ATS score or hiring prediction.

## Run it

Open `index.html` in a browser. The app is self-contained: no build step, packages, server, or API key are needed.

## Privacy

Matching runs in the browser. Pasted job descriptions are not uploaded, stored, or sent to an AI service. The source contains selected resume-derived project evidence so the demo can show its matches locally.
